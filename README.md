# Avito buddy

Дизайн-прототип AI-buddy для стажёров Авито: портал «Хаб» из ветки `landing` и галерея 40 пиксельных персонажей с прежним спутником.

## Структура

В корне проекта находятся Markdown-документы и две папки приложения:

```text
frontend/          Фронтенд на Next.js + React + TypeScript + Tailwind CSS, архитектура FSD
  src/             Код интерфейса, данные и отрисовка всех петов
  public/          Статические файлы
  design/          Изображения петов, анимации, скриншоты и отчёты проверок
  package.json     Команды и зависимости фронтенда
  package-lock.json
  .gitignore
backend/           Каталог будущей серверной части
AGENTS.md          Инструкции для агентов
TASK.md            Исходное ТЗ хакатона
PRODUCT.md         Согласованный объём продукта
DESIGN.md          Дизайн и анимации
CONTEXT.md         Общий журнал работы
README.md          Этот файл
```

## Запуск

Нужен Node.js 20.9+ и npm; для разработки рекомендуется актуальная LTS-версия Node.js. Все npm-команды выполняются в `frontend/`:

```sh
cd frontend
npm ci
npm run dev
```

- Главная: http://localhost:5173/
- Галерея: http://localhost:5173/pets
- Оригинальный Орби: http://localhost:5173/pets?pet=orbit

Из того же каталога:

```sh
npm test
npm run build
npm run check:architecture
npm run start
```

Сборка Next.js проверяет TypeScript и создаёт `frontend/.next/`. `npm run start` запускает production-сервер после сборки; порт по умолчанию 5173. Steiger проверяет направления импортов, независимость FSD-слайсов и публичные API. Подсказки о слайсах с одним потребителем остаются предупреждениями; нарушения границ — ошибки.

Фронтенд — самостоятельное приложение: его зависимости, lockfile и `node_modules/` находятся внутри `frontend/`. Корневого npm workspace больше нет.

Подробности архитектуры: [`frontend/README.md`](frontend/README.md). Состояние серверной части: [`backend/README.md`](backend/README.md).

## Возможности

- Портал: главная, профиль и сотрудники, сервисы, события, лента и статьи, преимущества, поиск и страница AI.
- Настройка быстрых действий, подписки, фильтры, реакции и комментарии на демонстрационных данных.
- 40 персонажей, по 4 кадра: исходные на 32×32, детальные вариации Орби на 64×64.
- Во вкладке «Орби» — оригинал и 15 его вариаций; в «Раньше» — предыдущая серия, в «Все» — весь каталог.
- Крупный просмотр, изменение масштаба, общая пауза анимации.
- Сердечки в карточках и предпросмотре, вкладка «Избранные» со счётчиком; лайки сохраняются отдельно от выбора спутника.
- Выбранный спутник появляется на страницах портала и в галерее и сохраняется в localStorage.
- Демонстрационные приветствия и скачивание SVG на прозрачном фоне.
- Мобильная версия, клавиатурный фокус, reduced motion.

Оригинальный Орби — самая первая версия с фиолетовыми боковыми деталями, ножками и розовым шарфом. Остальные 15 вариаций доработаны отдельно и парят без конечностей.

Это интерактивный прототип с локальными моками API портала и подготовленными ответами пета. AI, корпоративные интеграции, авторизация и другие сценарии полного ТЗ ещё не реализованы. Тестовые учётные данные и ключи API не нужны. Golos Text и пиксельный Press Start 2P подключены локально через next/font/local, без запросов к Google Fonts при запуске или сборке.

Все материалы петов и визуальных проверок: [`frontend/design/`](frontend/design/). Решения по интерфейсу: [`frontend/design/decisions.md`](frontend/design/decisions.md). Текущий контекст: [`CONTEXT.md`](CONTEXT.md).

## Стек и стили

Next.js 16 (App Router), React 19, TypeScript и Tailwind CSS 4. Все стили компонентов — utility-классы в TSX. `frontend/app/globals.css` содержит только подключение Tailwind и его TypeScript-конфига; отдельных CSS-файлов компонентов нет. Анимации и тема находятся в `frontend/tailwind.config.ts`.

Маршруты — `frontend/app/`. В FSD-слоях `src/_app` и `src/_pages` используется префикс, чтобы Next.js не принимал их за каталоги маршрутов. Остальные слои сохраняют прежние имена.

Портал перенесён с Vite на существующий Next.js/FSD; история `landing` сохранена merge-коммитом. Шрифт Inter портала подключён локально отдельно от шрифтов спутника. По умолчанию включены моки; параметры подключения реального API — в `frontend/.env.example`. Реализация серверной части остаётся отдельной задачей.
