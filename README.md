# Орби — AI-buddy для стажёров Авито

Помощник стажёра, встроенный в корпоративный портал. Орби ведёт по плану адаптации, отвечает на
вопросы о команде и инструментах со ссылками на источники, оформляет заявки в корпоративные сервисы
после подтверждения и передаёт людям то, что не может решить сам. Кейс Авито на хакатоне
Hack&Change 2026.

Все данные синтетические. Инструкции в базе знаний помечены «Тестовая инструкция, не регламент
Авито», корпоративные сервисы имитируются.

## Быстрый старт

Нужен Docker с Compose v2. GPU не нужен.

```sh
cp .env.example .env          # можно оставить пустым: Орби запустится в офлайн-режиме
docker compose up -d --build  # первый запуск ~3–5 минут
```

| Адрес | Что там |
|---|---|
| http://localhost | портал «Хаб» со спутником Орби |
| http://localhost/api/docs | Swagger UI всего API |
| http://localhost:8090/admin/state | состояние имитации корпоративных сервисов |

Проверка, что всё живо: `sh deploy/smoke.sh`. Скрипт входит под стажёром, читает план, просит Орби
оформить доступ, подтверждает карточку и показывает заявку.

### Подключение LLM

| | |
|---|---|
| Провайдер | OpenAI. Подходит любой OpenAI-совместимый API через `LLM_BASE_URL` (OpenRouter, Ollama, шлюзы) |
| Модели | `gpt-5.4-mini` — диалог и инструменты, `gpt-5.4` — фоновые сводки и поиск противоречий, `text-embedding-3-large` (1024) — поиск |
| Переменная | `LLM_API_KEY` в `.env` рядом с `docker-compose.yml` |

Пример `.env`:

```sh
LLM_API_KEY=sk-...
# LLM_BASE_URL=https://openrouter.ai/api/v1   # для совместимых провайдеров
# LLM_MODEL=gpt-5.4-mini
# LLM_REASONING_EFFORT=none                   # none | low | medium (только OpenAI Responses API)
MOCK_APPROVAL_DELAY_SEC=20                     # через сколько секунд «согласующий» примет решение
```

Без ключа Орби работает в офлайн-режиме: те же инструменты и сценарии, ответы строятся правилами,
поиск только полнотекстовый. Режим виден в интерфейсе и в `GET /api/v1/assistant/status`.
Если провайдер LLM отвечает ошибкой, Орби сам переключается на офлайн-режим и помечает это в ответе.

## Порядок проверки

Всё проходится в портале на http://localhost. При первом визите Орби проводит короткое знакомство —
его можно пропустить. Вход — кнопка «Войти» в шапке, на странице входа учётки выбираются одним кликом.

1. **План адаптации.** Войти Аней → «Мой путь»: этапы из чек-листа Авито, прогресс, «Сейчас важно»,
   статус ноутбука. У шагов кнопки «Начать», «Готово», «Есть блокер», «Инструкция» (документ из базы
   знаний), мини-тест «Изучи принципы разработки» и «На проверку наставнику».
2. **Заявка на доступ.** У шага «Получи доступ к репозиторию listings-api» нажать «Сделать с Орби» →
   открывается чат спутника, Орби готовит карточку: ресурс, уровень, согласующий, обоснование.
   «Изменить» позволяет поправить уровень и обоснование, «Подтвердить» отправляет заявку `ACC-…`.
   Шаг переходит в «Ждёт заявку»; через `MOCK_APPROVAL_DELAY_SEC` приходит веб-хук: пет сообщает
   «одобрено», шаг закрывается сам, в колокольчике уведомление со следующим шагом. История заявки —
   в «Заявки».
3. **Исключения.** «Нужен доступ к jira» → доступ уже есть, шаг закрывается сам. «Доступ к продовой
   базе» → ресурс не раскрывается. Отказ → `POST http://localhost:8090/admin/decide
   {"request_id": "ACC-1042", "status": "rejected"}`. Сбой сервиса → `POST /admin/faults
   {"mode": "unavailable"}`: заявка сохраняется и уходит повторно.
4. **Вопросы с источниками.** В чате «Куда отправлять PR?» → ответ со ссылками [1], [2], блок
   источников с датами обновления и предупреждение «Инструкции расходятся» с обеими цитатами и кнопкой
   «Уточнить у наставника».
5. **Нет ответа и деликатные темы.** «Как оформить командировку?» → карточка вопроса наставнику.
   «Сколько получает мой наставник?» → Орби не обсуждает и предлагает передать вопрос HRBP.
6. **Отгул и ноутбук.** «Хочу отгул в пятницу» → проверка остатка и встреч, предупреждения, карточка.
   «Когда выдадут ноутбук?» → статус, место выдачи, чем заняться до получения.
7. **Spotlight.** Два быстрых Enter в любом месте портала → строка «Спросить Орби». Короткий ответ пет
   печатает в пиксельной реплике, карточку открывает в чате.
8. **Наставник.** Войти Иваном → «Стажёры»: прогресс, блокеры, шаги на проверке. Кирилл → подтвердить
   или вернуть шаг с комментарием. Ответить на его вопрос с галочкой «Добавить в FAQ» → тот же
   вопрос у другого стажёра Орби найдёт в базе знаний.
9. **Метрики и аудит.** Марией или Ольгой → `GET /api/v1/analytics/summary`; администратором →
   `GET /api/v1/admin/audit` (Swagger UI).

Через Swagger UI проходится каждый шаг: `POST /api/v1/auth/login` с заголовком `X-Client: mobile`
вернёт токен для кнопки Authorize.

## Тесты и покрытие

```sh
make test       # поднимает тестовые Postgres (pgvector) и Redis в Docker и гоняет pytest
make check      # ruff, mypy --strict, тесты
make coverage   # покрытие бэкенда и фронтенда, общий отчёт в reports/coverage-summary.md
```

| Часть | Тесты | Покрытие строк |
|---|---|---|
| Бэкенд (`backend/app`) | 181 | 94,6% |
| Фронтенд (`frontend/src`, все файлы) | 115 | 93,9% |
| **Итого** | 296 | **94,3%** |

Интеграционные тесты бэкенда работают с настоящими Postgres и Redis, сценарии агента прогоняются на
детерминированной модели без сети. Тесты фронтенда используют записанные ответы и SSE-потоки
настоящего бэкенда (MSW): вход, чат с карточками, все экраны, realtime, пет и галерея. Имитация
корпоративных сервисов (`corp-mock/`) в покрытие не входит (№72 Q&A).

## Архитектура

```text
браузер ── nginx ──┬── web (Next.js: портал «Хаб», спутник Орби)
                   └── api (FastAPI) ──┬── Postgres 17 + pgvector
                                       ├── Redis (SSE, лимиты)
                                       └── corp-mock (MCP: доступы, отсутствия, календарь, IT, мессенджер)
                       worker ── outbox, AI-крон, сверка заявок, эмбеддинги
```

- Монолит со слоями `api → service → domain`: одна транзакция на запрос, outbox для побочных
  эффектов, RFC 7807 для ошибок, `mypy --strict`.
- Агент на Pydantic AI. Инструменты отфильтрованы по правам роли. Действие с последствиями
  показывается карточкой и выполняется только после подтверждения, с повторной проверкой прав и
  ключом идемпотентности.
- Корпоративные сервисы — порт `CorpServices` с MCP-адаптером. Реальная интеграция — новый адаптер.
- Поиск: полнотекстовый (русский) плюс векторный, ACL применяется в SQL до ранжирования.

Подробно: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Решения: [docs/DECISIONS.md](docs/DECISIONS.md).
Спецификации SDD (SpecKit): [specs/](specs/). Продукт: [PRODUCT.md](PRODUCT.md).


## Разработка

```sh
make install     # зависимости бэкенда, corp-mock и фронтенда
make test-deps   # Postgres и Redis для тестов и локального запуска
make corp-mock   # имитация сервисов на :8090
make run         # API с перезагрузкой на :8080 (нужен backend/.env, см. backend/.env.example)
make worker      # outbox и AI-крон
make frontend-dev   # портал на :5173, /api/v1 проксируется на API :8080 (ORBI_BACKEND_URL)
```

Фронтенд — самостоятельное приложение в `frontend/` (`npm ci`, `npm run dev`, `npm test`), подробности
в [frontend/README.md](frontend/README.md).
