# Avito buddy

Дизайн-прототип AI-buddy для стажёров Авито: главная-заглушка и галерея 40 пиксельных персонажей.

## Структура

В корне проекта находятся Markdown-документы и две папки приложения:

```text
frontend/          Фронтенд на React + TypeScript + Vite, архитектура FSD
  src/             Код интерфейса, данные и отрисовка всех петов
  public/          Статические файлы
  design/          Изображения петов, анимации, скриншоты и отчёты проверок
  package.json     Команды и зависимости фронтенда
  package-lock.json
  .gitignore
backend/           Каталог будущей серверной части
AGENTS.md          Инструкции для агентов
TASK.md            Исходное ТЗ хакатона
PRODUCT.md         Согласованный объём продукта
DESIGN.md          Дизайн и анимации
CONTEXT.md         Общий журнал работы
README.md          Этот файл
```

## Запуск

Нужен Node.js 22.12+ или 24+ и npm. Все npm-команды выполняются в `frontend/`:

```sh
cd frontend
npm ci
npm run dev -- --port 5173
```

- Главная: http://localhost:5173/
- Галерея: http://localhost:5173/pets
- Оригинальный Орби: http://localhost:5173/pets?pet=orbit

Из того же каталога:

```sh
npm run build
npm run check:architecture
npm run preview
```

Сборка проверяет TypeScript и создаёт `frontend/dist/`. Steiger проверяет направления импортов, независимость FSD-слайсов и публичные API. Подсказки о слайсах с одним потребителем остаются предупреждениями; нарушения границ — ошибки.

Фронтенд — самостоятельное приложение: его зависимости, lockfile и `node_modules/` находятся внутри `frontend/`. Корневого npm workspace больше нет.

Подробности архитектуры: [`frontend/README.md`](frontend/README.md). Состояние серверной части: [`backend/README.md`](backend/README.md).

## Возможности

- 40 персонажей, по 4 кадра: исходные на 32×32, детальные вариации Орби на 64×64.
- Во вкладке «Орби» — оригинал и 15 его вариаций; в «Раньше» — предыдущая серия, в «Все» — весь каталог.
- Крупный просмотр, изменение масштаба, общая пауза анимации.
- Сердечки в карточках и предпросмотре, вкладка «Избранные» со счётчиком; лайки сохраняются отдельно от выбора спутника.
- Выбранный спутник появляется в углу обеих страниц и сохраняется в localStorage.
- Демонстрационные приветствия и скачивание SVG на прозрачном фоне.
- Мобильная версия, клавиатурный фокус, reduced motion.

Оригинальный Орби — самая первая версия с фиолетовыми боковыми деталями, ножками и розовым шарфом. Остальные 15 вариаций доработаны отдельно и парят без конечностей.

Это этап визуального дизайна. AI, корпоративные интеграции, авторизация и другие сценарии полного ТЗ ещё не реализованы. Тестовые учётные данные и ключи API не нужны. Golos Text загружается через Google Fonts; без сети используется системный шрифт.

Все материалы петов и визуальных проверок: [`frontend/design/`](frontend/design/). Решения по интерфейсу: [`frontend/design/decisions.md`](frontend/design/decisions.md). Текущий контекст: [`CONTEXT.md`](CONTEXT.md).
