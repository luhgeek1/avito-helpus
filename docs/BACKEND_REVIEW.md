# Доводка и ревью бэкенда Орби

14.11.2026, ветка `feat/observability-clickstream`. Только синтетические данные.
Изменения наблюдаемости и Clickstream сохранены. Коммитов и push нет.

## Область и способ проверки

Прочитаны API и схемы, сервисы вне `service/assistant`, доменные правила вне `domain/assistant.py`,
модели и репозитории, UoW, адаптеры вне `infra/llm.py`, worker, CLI, loader, миграции и corp-mock.
Проверены границы RBAC/ABAC, транзакций и outbox, обработка повторов, отмен, отказов и сброса демо,
формат ошибок и время. Код поиска и ассистента не изменялся.

Использованы регрессионные тесты с настоящими Postgres на 5439 и Redis на 6380, MCP-сервер в памяти,
проверка миграций вниз/вверх, а также HTTP-нагрузка на отдельный локальный API. Это не аудит
развёрнутого production и не доказательство отсутствия всех возможных дефектов.

## Короткие номера заявок после приёмки

Нумерация после приёмки уточнена в D-022: вместо суффикса ключа — короткий номер и отдельный
`state.sequences.json`, резервируемый до возврата результата. Обычный reset и потеря state.json
не откатывают нумерацию. Согласованный reset сначала очищает API, затем явно возвращает счётчики
mock к демо-значениям. Проверены `ACC-1042` для первой заявки Ани, `ABS-2101`, `IT-3301`, продолжение
после reset/рестарта/потери снимка, устаревший снимок и старые длинные номера. При полной потере
тома mock с сохранённой БД API по-прежнему действует защита от постоянной коллизии без retry.

## Приёмка на живом Docker-стеке (Windows 11, Docker Desktop)

- `docker compose down -v && docker compose up -d --build` с нуля, затем `sh deploy/smoke.sh` → `Заявка ACC-1042: На согласовании`, exit 0;
  до доводки smoke на Windows молча «проходил» при HTTP 400.
- Сценарный прогон (флагман доступа, исключения, отгул, ноутбук, эскалация, права): веб-хук через 20 с → «Одобрено»,
  шаг плана закрыт (9% → 12%), уведомления; Дана → чужой документ и подопечный 404, стажёр → сводка 403.
- `python deploy/reset_demo.py` → «Демо сброшено в обеих системах», затем smoke снова даёт `ACC-1042`.
  Отдельный сброс только corp-mock (`POST :8090/admin/reset`) → новая заявка `ACC-1043`, без коллизии и зависания.
- Профили `observability` и `clickstream` с `CLICKSTREAM_ENABLED=true`: цели Prometheus `api`/`worker` up, 10 правил
  без ошибок; дашборды «Орби — техника» и «Орби — польза» отрисованы (польза — через read-only роль); события
  `analytics.publish` доставлены в `buddy.analytics.v1`, потребитель сохраняет; envelope без ПДн (актор — HMAC).
- `python deploy/loadtest.py --users 20 --duration 60 --base-url http://localhost` (через nginx): ошибок 0;
  простые операции p95 116–190 мс, p99 ≤ 341 мс; чат (офлайн, полный ответ с SSE) p95 1,35 с, 429 — лимит сообщений.
