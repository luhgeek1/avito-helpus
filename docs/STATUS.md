## Готово

- **React SDK (D-040):** `frontend/packages/react`, устанавливаемый `.tgz`, типизированный
  `OrbiCompanion` для React 19 и Next.js. Стили/шрифты внутри и изолированы в Shadow DOM;
  Next.js, MSW и React в сборку не включены. Сохранён общий код всех персонажей, гардероба,
  настроек, чата, Spotlight, подтверждений и уведомлений. [Инструкция](../frontend/packages/react/README.md).
- **Подключение платформы:** runtime API URL, cookie-вход внутри виджета, callback токена,
  sessionKey, переходы, CSP nonce, ref-команды. Смена сессии отменяет запросы и удаляет
  приватные данные. Предпочтения и оригинальные четыре кадра `orbit` сохранены.
- **Контекст:** операторский импорт Markdown с ролями и company/team, проверкой команды,
  транзакцией на весь пакет, `--check` и явным `--replace`. Поиск и outbox прежние.
  MCP работает через существующий серверный контракт, произвольным серверам нужен адаптер.
  [Настройка](integration/SDK_SERVER.md).
- **Проверка поставки:** настоящий архив установлен и собран в независимых React/Vite и Next.js.
  В браузере проверены 1440 и 390 px, React 19.1 и 19.3, CSS хоста, чат и повторный клик,
  Spotlight, гардероб, настройки, тур, unmount/remount. Настоящий API + Postgres/Redis + worker
  + MCP: импортированный документ → ответ с источником → доступ → подтверждение → webhook →
  SSE-уведомление. [Отчёт и снимки](../frontend/design/captures/sdk/verification.json).
- **Качество:** фронтенд — 220 тестов и 3738/3738 строк; SDK — 8 тестов и 133/133 строк.
  TypeScript, архитектура (8 прежних рекомендаций) и production build проходят.
  Бэкенд — 432 теста, 6376/6376 строк; make check проходит. Покрытие SDK включено в общий отчёт,
  CI проверяет установку архива в независимые приложения. Старый снимок D-032 — исторический.
- **Главная и демо (D-038, D-039):** `/` объясняет установку библиотеки и сервера, блоки кода
  копируются; Орби помогает локально по руководству. `/demo` — прежний портал с настоящим
  агентом, авторизацией и карточками. Повторный клик по пузырю закрывает чат с сохранением истории.
- **Основной продукт:** сценарии адаптации, доступов, отсутствий, IT, знаний с ACL, эскалации,
  наставник, аналитика, аудит, флаги, outbox, веб-хуки и SSE сохранены.
  [Архитектура](ARCHITECTURE.md), [спецификации](../specs/README.md).

## Дальше

- Библиотека ещё не опубликована в npm. Нужны аккаунт/организация npm и доступный scope,
  выбранная лицензия своего кода и выпуск версии; затем `npm publish --access public`.
  Архив можно устанавливать и передавать уже сейчас. Публичная публикация намеренно блокируется
  prepublish-проверкой, пока лицензия не выбрана.
- По просьбе пользователя изменения остаются в отдельной ветке, без слияния в main и деплоя.
- Для другой компании: серверный обмен SSO, оргструктура, документы и адаптеры сервисов.
- Сдача хакатона: видео полного сценария, презентация PDF и загрузка решения.
