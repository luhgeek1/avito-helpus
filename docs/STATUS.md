# Статус

Обновлено: 14.11.2026. Дедлайн загрузки: 16.11.2026 14:00 МСК.

## Готово

- **Бэкенд** (`backend/`): FastAPI-монолит по шаблону команды. План адаптации из чек-листа Авито,
  заявки на доступ, отгул и IT с подтверждением, гибридный поиск с ACL и противоречиями, эскалации
  наставник → руководитель → HRBP с FAQ, экран наставника, уведомления и SSE, аналитика, флаги, аудит.
  50 эндпоинтов, OpenAPI — `docs/api/openapi.json`.
- **Агент Орби** на Pydantic AI: `gpt-5.4-mini` (Responses API), карточки подтверждения, офлайн-режим
  и автоматический фоллбэк. Проверено на живой модели: первый токен ≈ 1–2,5 с.
- **Фронтенд подключён к API**: вход с демо-учётками, «Мой путь», «Заявки и вопросы», «Стажёры»
  (экран наставника), живые уведомления в шапке. Чат спутника и Spotlight работают с настоящим агентом:
  источники, противоречия, карточки с правкой полей, заявки, офлайн-бейдж; пет озвучивает уведомления.
  Флагман пройден в браузере на живой модели: «Сделать с Орби» → карточка → правка уровня →
  подтверждение → веб-хук → шаг закрыт, пет сообщает об одобрении. Десктоп и телефон проверены.
- **corp-mock** — MCP-имитация сервисов доступов, отсутствий, календаря, IT и мессенджера с
  веб-хуками и имитацией сбоев.
- **Запуск для жюри**: `docker compose up -d --build`, сид и ключи создаются сами;
  `deploy/smoke.sh` проходит флагманский сценарий.
- **Качество**: 296 тестов (бэкенд 181, фронтенд 115), общее покрытие строк 94,3%
  (`make coverage` → `reports/coverage-summary.md`). ruff, mypy --strict, tsc, steiger — чистые.
- **Документы**: README для жюри с порядком проверки через интерфейс, ARCHITECTURE, DECISIONS
  D-001…D-013, SpecKit-спецификации и CJM, гайд API для фронтенда.
