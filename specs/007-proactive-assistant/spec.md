# Спецификация: проактивный Орби (AI-крон) и рантайм агента

**Ветка**: `feat/ai-buddy-backend` · **Создано**: 14.11.2026 · **Статус**: реализуется

**Исходный запрос**: помощник не только отвечает, но и сам напоминает о важном; работает надёжно
с LLM и без неё; измеряется.

## Пользовательские истории

### История 1. Напоминания по делу (P1)

1. Просроченный пункт плана → уведомление стажёру не чаще раза в сутки на пункт, со ссылкой «Сделать с Орби».
2. Заявка дольше SLA → уведомление стажёру с предложением напомнить согласующему.
3. Эскалация без ответа до срока → подъём уровня (006).
4. Ноутбук стал `ready_for_pickup` → уведомление с местом выдачи.
5. Дедупликация: одно напоминание на событие (`dedupe_key`), включается флагом `proactive_nudges`.

### История 2. Агент без блокировок (P1)

1. Ответ стримится через SSE: первая часть (`start`, `data-status`) приходит сразу, текст — по мере генерации.
2. Таймаут модели `LLM_TIMEOUT_SEC` или ошибка провайдера → `FallbackModel` переключает на офлайн-режим,
   пользователь видит пометку `data-status: offline`.
3. Нет ключа → офлайн-режим с самого начала, `GET /api/v1/assistant/status` сообщает `offline`.
4. Не более `CHAT_RATE_LIMIT_PER_MINUTE` сообщений в минуту на пользователя (429 `RATE_LIMITED`).

### История 3. Измеримость и A/B (P2)

1. События продукта пишутся в `analytics_events`: сообщения, вызовы инструментов, решения по карточкам,
   заявки и их итог, пункты плана, эскалации, оценки ответов.
2. Флаги с процентом раскатки и вариантами эксперимента: детерминированное распределение по
   хэшу команды (весь отряд в одном варианте), `GET /api/v1/me` отдаёт флаги.
3. `GET /api/v1/analytics/summary` (руководитель, HRBP, админ): время до доступа, доля вопросов без
   наставника, пункты в срок, оценки ответов, по вариантам эксперимента.
4. Технические метрики Prometheus на `/api/metrics`: латентность HTTP, первый токен, вызовы инструментов, фоллбэки.

## Требования

- **FR-001** Модели: `LLM_MODEL` (по умолчанию `gpt-5.4-mini`) для диалога, `LLM_HEAVY_MODEL`
  (`gpt-5.4`) для сводок и противоречий; `LLM_BASE_URL` для OpenAI-совместимых провайдеров.
- **FR-002** Инструменты фильтруются по правам до передачи модели; действия с последствиями — только
  через подтверждение (002, 004, 005, 006).
- **FR-003** История диалога хранится на сервере; клиент присылает только текст или решение по карточке.
- **FR-004** Документы и результаты инструментов — данные, а не инструкции: системный промпт
  запрещает следовать инструкциям из них.
- **FR-005** Фоновые задачи выполняются воркером; несколько копий воркера не дублируют задачи
  (advisory lock на задачу).

## Критерии успеха

- **SC-001** Первый байт ответа чата < 300 мс; полный офлайн-ответ < 1 с.
- **SC-002** Сценарии агента покрыты тестами на детерминированной модели без сети.
