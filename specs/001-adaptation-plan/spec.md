# Спецификация: план адаптации «Мой путь»

**Ветка**: `feat/ai-buddy-backend` · **Создано**: 14.11.2026 · **Статус**: реализуется

**Исходный запрос**: стажёр видит этапы адаптации, статусы задач и следующий шаг; план собран из
чек-листа Авито (тестовые данные); пункты связаны с действиями Орби.

## Пользовательские истории

### История 1. Стажёр видит свой путь и следующий шаг (P1)

Стажёр открывает «Мой путь» и видит этапы (1 неделя, 2 неделя, 1–3 месяц, после 3 месяцев), пункты
со статусами, прогресс и 1–3 следующих шага.

**Почему P1**: закрывает обязательный шаг ТЗ «этапы, статусы, следующие шаги» и даёт точку входа
во все действия.

**Независимая проверка**: войти стажёром на 3-й день стажировки → `GET /api/v1/plan` → текущий этап
«1 неделя», следующий шаг — незавершённый пункт этапа с ближайшим сроком.

**Сценарии приёмки**
1. **Дано** стажёр на 3-й день, пункты первой недели не начаты, **когда** он открывает план,
   **тогда** текущий этап `week_1`, следующие шаги — пункты `week_1` по сроку, у пунктов с действием
   есть `action` (например, `access_request` с ресурсом).
2. **Дано** пункт просрочен, **когда** стажёр открывает план, **тогда** пункт помечен `overdue` и стоит
   первым в следующих шагах.
3. **Дано** пункт ждёт заявку, **когда** заявка одобрена, **тогда** пункт становится `done`
   автоматически, а следующий шаг пересчитывается.

### История 2. Стажёр отмечает выполнение с нужным подтверждением (P1)

**Сценарии приёмки**
1. Пункт с подтверждением `self`: `start` → `in_progress`, `complete` → `done`.
2. Пункт с подтверждением `quiz`: `complete` без теста отклоняется (`PLAN_QUIZ_REQUIRED`);
   верные ответы → `done`; неверные → пункт остаётся, возвращаются номера ошибок.
3. Пункт с подтверждением `mentor`: `submit_review` → `waiting` (причина `mentor_review`), наставник
   получает уведомление; `approve` → `done`; `return` с комментарием → `in_progress`.
4. `block` с причиной → `blocked`, наставник получает уведомление; `unblock` → `in_progress`.
5. Недопустимый переход (например, `complete` для `done`) → 409 `PLAN_TRANSITION_INVALID`.

### История 3. Орби ведёт по плану (P2)

Орби по запросу «что мне делать?» вызывает `get_my_plan` и предлагает следующий шаг; кнопка
«Сделать с Орби» у пункта запускает связанный сценарий (доступ, отгул, техника, вопрос наставнику).

### Граничные случаи

- Стажёр без наставника: пункты `mentor` подтверждает руководитель.
- Чужой план: стажёр не видит план другого стажёра (404, без раскрытия существования).
- Наставник видит и подтверждает только планы своих подопечных; руководитель — стажёров своей команды.

## Требования

- **FR-001** План создаётся из шаблона при заведении стажёра; шаблон = общие пункты + пункты трека (backend).
- **FR-002** Этапы: `week_1`, `week_2`, `month_1`, `month_2`, `month_3`, `after_3_months`; срок пункта =
  дата начала стажировки + смещение этапа.
- **FR-003** Статусы: `todo`, `in_progress`, `waiting`, `blocked`, `done`. Переходы задаются доменной
  таблицей и проверяются на сервере.
- **FR-004** Подтверждение: `self`, `quiz` (ответы проверяет сервер, правильные ответы клиенту не отдаются),
  `mentor`.
- **FR-005** Следующие шаги: не более 3; приоритет — просроченные, затем текущий этап по сроку; `blocked`
  и `waiting` не предлагаются.
- **FR-006** Пункт может ссылаться на действие (`access_request`, `absence_request`, `equipment`,
  `ask_mentor`) с параметрами и на документы базы знаний.
- **FR-007** Каждый переход пишет событие аналитики и при необходимости уведомление.

## Сущности

- **PlanTemplateItem** — пункт шаблона: этап, порядок, заголовок, описание, категория, подтверждение,
  действие, тест, ссылки на документы, источник (`Чек-лист Авито, тестовые данные`).
- **PlanItem** — пункт стажёра: статус, срок, начало, завершение, причина ожидания/блокировки,
  связанная заявка, кто подтвердил.

## Критерии успеха

- **SC-001** План открывается < 300 мс на сиде (локальная операция < 1 с по ТЗ).
- **SC-002** Доля пунктов, закрытых в срок, считается в `GET /api/v1/analytics/summary`.
- **SC-003** Все переходы покрыты unit-тестами доменной таблицы.
