Общие правила код-ревью для всех команд демо-компании.

## Куда отправлять PR и сколько нужно аппрувов
<!-- topic: code_review.rules -->
Pull request открывается в ветку main. Для мержа нужно два аппрува от любых участников команды.
Ревьюеров автор выбирает сам из списка участников репозитория.

## Сроки ревью
Ревьюер смотрит PR в течение рабочего дня. Если ревью не начато за день, напомни в канале команды.

## Что проверяет ревьюер
Корректность и тесты, читаемость, соответствие архитектуре и кодстайлу, отсутствие секретов в коде.
Код, сгенерированный LLM, проверяется так же строго, как написанный вручную.
