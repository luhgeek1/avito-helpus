Как начать работать с репозиториями в Stash (Bitbucket) демо-компании.

## Как скачать репозиторий
Сначала добавь свой SSH-ключ в профиль Stash (раздел «SSH keys»). Затем клонируй репозиторий по SSH:
`git clone ssh://git@stash.buddy.test:7999/lst/listings-api.git`. Если доступа к репозиторию нет —
запроси его через Орби, уровень «редактирование».

## Как называть ветки
<!-- topic: git.branches -->
Ветки называются по шаблону feature/<короткое-описание>, например feature/fix-price-validation.

## Как открыть PR
Запушь ветку, открой pull request в интерфейсе Stash, заполни описание: что сделано, как проверить,
ссылка на задачу. Правила ревью — в регламенте код-ревью.
