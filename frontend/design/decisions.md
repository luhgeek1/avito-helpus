# Решения

- 2026-11-10: локальный React + TypeScript + Vite. Две страницы без серверной логики; штатная History API поддерживает переходы назад и прямые адреса.
- Петы сделаны кодом на сетке 32×32 и выводятся SVG. Это позволяет править отдельный пиксель и проверять каждый кадр; растровая генерация здесь не нужна.
- Выбраны десять различных силуэтов: кот, корги, сова, робот, лис, лягушонок, пингвин, аксолотль, росток и дракончик.
- Светлая оболочка и спокойные пастельные сцены сохраняют акцент на персонажах. Главная не содержит обещаний о работающих AI-интеграциях.
- Выбранный пет появляется в углу; выбор сохраняется на этом устройстве. Приветствия заранее подготовлены и служат только демонстрацией.
- Пользователь дал свободу оформления; отдельные согласования направлений не требовались. Прототип доступен для дальнейшего визуального выбора.

- 2026-11-10: по запросу пользователя разделены `frontend/` и `backend/`. Фронтенд переведён на FSD с публичными API и проверкой Steiger; общая установка и корневые команды организованы через npm workspaces. Стили разделены по владельцам. `backend/` пока содержит README, без преждевременного выбора серверного фреймворка.

- 2026-11-10: пользователь попросил ещё 15 вариантов оригинального маскота Авито вместо обычных животных. Добавлена отдельная категория `mascots`, новая серия открывается первой, исходные 10 остаются для сравнения. В основе — четыре фирменных цвета и идеи связи, поиска, обмена и общения. Новые рисунки отделены в `entities/pet/lib/mascot-sprites.ts`, общие пиксельные примитивы вынесены в `pixel-painter.ts`; FSD-границы сохранены.

- 2026-11-10: пользователь выбрал визуальным ориентиром Орби с присланной картинки. Добавлены 15 родственных вариантов в категории `orbi`; параметры корпуса, деталей, зрачка и палитры отделены в `config/orbi-family.ts`, отрисовка — в `lib/orbi-sprites.ts`. Один большой глаз и спутники сохраняют узнаваемость семейства. Палитры включают варианты за пределами фирменных четырёх цветов по прямому пожеланию пользователя. Новая серия первая, предыдущие 25 — в «Раньше», весь каталог 40 — в «Все».

- 2026-11-10: по уточнению пользователя Орби стал парящим одноглазым роботом без конечностей. У 15 вариаций и исходного Орби убраны ноги, двигатели и боковые детали, похожие на руки; частицы отделены от корпуса. Добавлена FSD-фича `pet/favorite`, локальное хранение лайков отдельно от выбранного пета и вкладка «Избранные». Карточка принимает слот actions, чтобы не импортировать фичу из слоя сущностей и не вкладывать кнопки друг в друга.

- 2026-11-10: по просьбе пользователя оригинальный `orbit` со скриншота возвращён первым во вкладке «Орби» и как стандартный предпросмотр. Рисунок подтверждён по всем четырём кадрам. Добавлена ссылка `?pet=orbit`; сохранённые лайки и выбранный спутник не сбрасываются. Вкладка «Орби» содержит оригинал + 15 вариантов, общий каталог остаётся без дублей.

- 2026-11-10: 15 вариаций получили независимую детальную отрисовку 64×64 с разными материалами, оптикой и частицами. Оригинальный `orbit` не проходит через этот рендерер. Пользователь уточнил первоначальный референс: восстановлен исходный `orbit` с боковыми деталями, ножками и шарфом, по всем 4 кадрам первого снимка данных. Избранные и ID не сбрасывались.

- 2026-11-10: по запросу пользователя в корне оставлены только Markdown-документы и папки frontend/backend. Все материалы петов перенесены в `frontend/design/`, фронтенд стал самостоятельным npm-приложением с локальными manifest, lockfile, зависимостями и .gitignore. Код и изображения персонажей при переносе не менялись.


## 2026-11-11 — Next.js и Tailwind

По запросу пользователя Vite заменён на Next.js App Router, а CSS компонентов — на Tailwind utilities. Визуальная система и все персонажи сохранены. FSD-слои app/pages переименованы в _app/_pages, чтобы Next.js не сканировал их как маршруты. next/font/local подключает локальные Golos Text и Press Start 2P. CSS entry содержит только две директивы Tailwind, keyframes вынесены в TypeScript-конфиг. Координаты, палитры и задержки спрайтов остаются динамическими style-значениями. Проверка localStorage после гидратации сохраняет существующие лайки.


## 2026-11-11 — Компактный плавный гардероб

По скриншоту пользователя убраны кнопки-стрелки, радиус дуги уменьшен до 146/124 px, шаг — до 24°. Вместо отдельных CSS-переходов с блокировкой на 280 мс используется непрерывное движение с критическим затуханием через requestAnimationFrame; скорость сохраняется при повторном вводе. Раскрытие остаётся отдельным плавным переходом, reduced motion — мгновенным. Фокус после раскрытия переходит на регион карусели; листание клавиатурой сохраняется без экранных стрелок.


## 2026-11-11 — Чат с историей над петом

Кнопка с облачком открывает отдельное окно переписки над спутником. Тёмный квадратный контур и пиксельный заголовок продолжают стиль реплики, основной текст остаётся читаемым Golos Text. История прокручивается внутри, поле ввода закреплено снизу. Подготовленный диалог и новые сообщения с моковыми ответами хранятся в buddy-chat независимо от выбора и избранного. При нехватке места сверху окно открывается снизу; visualViewport позволяет удерживать его в видимой области. Двойная активация пета по-прежнему вызывает короткое приветствие.
