# Хаб — фронтенд внутреннего портала

Внутренний портал сотрудника: главная, сервисы, бенефиты («Плюсы»), события, лента, профиль. Структура повторяет портал «Майти», визуальный стиль — сайт avito.ru. Пока все данные замоканы: запросы перехватывает [MSW](https://mswjs.io), бэкенд подключается без правок в UI.

## Стек

React 19 · TypeScript · Vite · TanStack Router · TanStack Query · Zustand · Zod · MSW · Vitest + Testing Library · lucide-react (иконки). Стили — CSS Modules и дизайн-токены в `src/index.css`.

## Дизайн

Токены сняты с дизайн-системы avito.ru (переменные `--theme-semantics-*`). Шрифт у Авито — собственный Avito Sans (не публичный, файлы нужно получить у дизайн-команды); пока используется Inter в начертаниях 400 и 700 — из публичных шрифтов с кириллицей он ближе всех к Avito Sans. Текст 15/20, заголовки 32/36 и 26/30 весом 700. Кнопки: `accent` — синяя `#00AAFF` для ключевого действия, `primary` — чёрная `#141414`; высоты 36/44/52, у каждой есть цвет нажатия. Ссылки `#0099F7`, при наведении красные `#FF4053`. Контролы — тёплый серый `#F2F1F0`, плитки — `rgba(0,0,0,.04)`, фокус — кольцо `3px #45C1FF`, радиусы 12/16/24. Контент шириной 1316 px, карточки около 250 px с отступами 16/24 и квадратными обложками. Вместо 3D-иллюстраций Авито — эмодзи из поля `emoji` в данных.

## Переменные окружения

Скопируйте `.env.example` в `.env.local`.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `VITE_API_BASE_URL` | `/api` | базовый адрес API |
| `VITE_API_MOCKS` | `true` | `false` — отключить MSW и ходить в настоящий бэкенд. Если браузер не даёт зарегистрировать сервис-воркер (приватное окно Firefox, дев-сервер по IP без HTTPS), моки работают через перехват `fetch` |

## Как устроено

```
src/
  api/        client.ts — fetch + Zod-валидация ответа; schemas.ts — контракт API; queries.ts — хуки TanStack Query
  mocks/      data.ts — синтетические данные; handlers.ts — эндпоинты MSW; db.ts — изменяемое состояние
  stores/     Zustand: настройки пользователя (persist в localStorage)
  app/        роутер и провайдеры
  components/ layout (шапка, футер, опрос), feed (карточки постов, каналы), ui (кнопки, аватары, обложки, модалка)
  pages/      страницы
```

**Подключение бэкенда.** Контракт описан Zod-схемами в `src/api/schemas.ts`, эндпоинты — в `src/mocks/handlers.ts`. Бэкенд должен отдавать те же пути и формы ответов, после чего достаточно выставить `VITE_API_MOCKS=false`. Если ответ не совпадёт со схемой, клиент сразу бросит `ApiError` «неожиданный формат».

### Эндпоинты

| Метод | Путь | Ответ |
| --- | --- | --- |
| GET | `/me`, `/people/:id` | профиль сотрудника |
| GET | `/banners`, `/quick-actions`, `/birthdays`, `/promos` | блоки главной |
| GET | `/services`, `/services/:id` | каталог сервисов |
| GET | `/benefits`, `/benefits/:id` | категории «Плюсов» с сервисами и статьями |
| GET | `/channels` · POST `/channels/:id/subscription` `{subscribed}` | каналы ленты и подписка |
| GET | `/posts?channel=`, `/posts/:id` · POST `/posts/:id/like` `{liked}` | лента и лайки |
| GET | `/events?category=&format=&period=&q=` · POST/DELETE `/events/:id/registration` | события и запись |
| GET | `/notifications` · POST `/notifications/read-all` | уведомления |
| GET | `/calendar?date=YYYY-MM-DD` | встречи на день |
| GET | `/search?q=` | поиск по людям, сервисам, событиям и постам |
| POST | `/feedback` `{value}` | оценка портала |

## Данные

Все люди, тексты, условия и правила вымышлены и **не являются регламентами Авито**. Приватные вкладки профиля (личные данные, документы, ревью, обучение) видны только владельцу.
