# Frontend

Next.js 16.4, React 19, TypeScript и Tailwind CSS 4.3. Приложение следует Feature-Sliced Design; Next.js App Router отвечает за входные маршруты.

```text
app/
  layout.tsx                     Серверный layout, metadata и локальные шрифты
  page.tsx                       Главная /
  pets/page.tsx                  Галерея /pets и параметр ?pet=orbit
  globals.css                    Только подключение Tailwind и его конфига
src/
  _app/                          Клиентские провайдеры и композиция оболочки
  _pages/                        Главная и галерея
  widgets/                       Оболочка, коллекция, инспектор, спутник
  features/pet/                  Выбор, лайки, SVG, приветствие, пауза
  entities/pet/                  Данные, предпочтения, спрайты и UI петов
  shared/                        Общая конфигурация и фирменный знак
public/fonts/                    Локальные шрифты и OFL-лицензии
tailwind.config.ts               Тема, брейкпоинты и keyframes
postcss.config.mjs               Плагин Tailwind
next.config.ts                   Настройки Next.js
design/captures/                 Скриншоты и отчёты проверок
```

## Архитектура

- Направление импортов: `_app → _pages → widgets → features → entities → shared`. Префиксы `_app` и `_pages` исключают конфликт с зарезервированными каталогами Next.js.
- Каталог маршрутов `app/` импортирует публичные API FSD. Клиентская композиция находится в `src/_app`; страницы публикуются из `src/_pages/*/index.ts`.
- Слайсы одного слоя независимы. Между слайсами используй публичные API, например `@/entities/pet`, а внутри слайса — относительные импорты.
- Страница галереи — клиентская граница, её серверный маршрут передаёт разобранный searchParams. Metadata и локальные шрифты подключаются на сервере.
- Предпочтения читаются из localStorage после гидратации. До загрузки сохранённых лайков запись отключена, поэтому существующее избранное не затирается пустым массивом.
- Навигация использует Next Link и Next router. Layout сохраняет провайдер и спутника при переходах между страницами.

Steiger проверяет границы слоёв; только подсказка о префиксах `_app`/`_pages` отключена для этих каталогов. Существующие рекомендации об одном потребителе остаются предупреждениями.

## Стили

Используй Tailwind utility-классы прямо в TSX, включая адаптивность, состояния, псевдоэлементы и reduced motion. Не добавляй обычные CSS-файлы компонентов, CSS Modules или CSS-in-JS. `app/globals.css` — двухстрочная точка входа Tailwind, а тема и анимации задаются в `tailwind.config.ts`. Inline style допустим только для данных времени выполнения: положения спутника, палитры выбранного пета, масштаба и задержки кадров SVG.

Брейкпоинты сохраняют прежний дизайн: xs — 361 px, sm — 651 px, md — 851 px, lg — 1201 px, xl — 1600 px. Golos Text и Press Start 2P подключены через next/font/local. Лицензии рядом со шрифтами.

## Запуск и проверки

Из `frontend/`, нужен Node.js 20.9+:

```sh
npm ci
npm run dev
npm run typecheck
npm run check:architecture
npm run build
npm run start
```

Dev и production-сервер по умолчанию доступны на http://localhost:5173/. Для другого порта: `npm run dev -- --port 3000`. Production start выполняется после build. Артефакты Next.js находятся в `.next/` и игнорируются Git. Vite и старый React DOM entrypoint удалены. Корневого npm workspace нет.

## Петы и состояние

Всего 40 персонажей, по четыре кадра. «Орби» — оригинал и 15 вариаций (16), «Раньше» — 25, «Все» — 40. Оригинал `orbit` находится в обеих тематических группах, без дублирования общего каталога. `/pets?pet=orbit` открывает его в предпросмотре, не меняя сохранённого спутника.

Оригинальный Орби рисуется в `entities/pet/lib/mascot-sprites.ts` на 32×32 с боковыми деталями, ножками и шарфом. Его четыре исходных кадра сохраняются. Вариации `orbi-*` рисуются отдельно на 64×64: `orbi-base.ts`, `orbi-sprites.ts`, `orbi-details.ts`, `orbi-detail-painter.ts`. Они парят без конечностей. Данные и палитры — в `entities/pet/config/`.

Избранное хранится в `buddy-favorites`, выбранный спутник — в `buddy-pet`, положение — в `buddy-position`. Спутника можно перетаскивать мышью/пальцем или двигать стрелками. Одиночный клик/тап раскрывает три пиксельных кружка по дуге: чат, гардероб и настройки. Двойной клик/тап или два Enter открывают пиксельную реплику с печатью по буквам; у краёв окно меняет сторону. Кнопка «Показать сразу» завершает печать. При reduced motion или паузе весь текст виден сразу.

UI-проверки: `design/captures/verify-next-migration.mjs`, `verify-pixel-dialogue.mjs`, `verify-companion-drag.mjs`, `verify-orbit-menu.mjs`, `verify-wardrobe-carousel.mjs`. Используют Playwright из локальной установки design-studio; при другом окружении укажи установленный Playwright в import.

Общие требования — `../AGENTS.md`, дизайн — `../DESIGN.md`, история — `../CONTEXT.md`.

Гардероб спутника — локальная круговая карусель всех 40 персонажей с пятью видимыми миниатюрами и бесконечным зацикливанием. Колёсико, свайп, стрелки и клавиатура листают без изменения выбора. Клик выбирает пета через общий choosePet и сохраняет buddy-pet; избранное не меняется. Логика и UI находятся внутри widgets/pet-companion, каталог берётся из публичного entities/pet API.
