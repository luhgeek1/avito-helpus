Пакет включает код TanStack Query, Zustand, Zod, tailwind-merge (MIT), иконки Lucide (ISC),
а также шрифты Golos Text и Press Start 2P (SIL Open Font License).
Полные тексты лицензий и уведомления авторов поставляются в `dist/licenses/`;
уведомления внутри кода — `dist/index.js.LEGAL.txt`.
React и React DOM не включены в сборку и устанавливаются приложением отдельно.
